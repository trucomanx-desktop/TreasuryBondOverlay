# treasury-bond-overlay

Display multiple time zones as always-on-top desktop clocks.


## Install from PYPI

The homepage in pipy is https://pypi.org/project/treasury-bond-overlay/

```bash
pip install --upgrade treasury-bond-overlay
```

Using:

```bash
treasury-bond-overlay
```

## Install from source
Installing `treasury-bond-overlay` program

```bash
git clone https://github.com/trucomanx-desktop/TreasuryBondOverlay.git
cd TreasuryBondOverlay
pip install -r requirements.txt
cd src
python3 setup.py sdist
pip install dist/treasury_bond_overlay-*.tar.gz
```
Using:

```bash
treasury-bond-overlay
```

## Uninstall

```bash
pip uninstall treasury_bond_overlay
```
